# RapidTyper

> **Repository Status: Archived**
>
> This repository is archived and no longer actively maintained. The school festival typing competition has ended, and this codebase is preserved strictly for reference.

## About the Project

RapidTyper was built as a touch-typing competition platform for our school festival.

During the event, participants tested their typing speed and accuracy live under time limits to compete for real prizes. Because the festival has finished and the competition concluded, the project has served its purpose and is now permanently retired.

## Running Locally

This is a lightweight static web app:

1. Clone the repository:

    git clone https://github.com/Dany0443/RapidTyper.git
    cd RapidTyper

2. Start a local server:

    python3 -m http.server 8000

3. Open http://localhost:8000 in your web browser.
